# Glosario español de Atlas

Este glosario fija términos para las páginas públicas de Atlas en España. El objetivo es mantener un español claro, profesional y coherente sin perder precisión técnica.

| Concepto | Término recomendado | Nota de uso |
| --- | --- | --- |
| candidate location | ubicación en estudio | Evitar repetir “candidato” en titulares públicos. |
| research stage | fase de estudio | Usar “fase Atlas” cuando se refiera al gate público. |
| project gate | fase Atlas / Gate | Mantener “Gate” si aparece como etiqueta de metodología. |
| demand-side grid capacity | potencia de red para consumo | No confundir con capacidad de generación. |
| site control | terreno bajo control | Usar solo si existe opción, compra, alquiler o derecho equivalente. |
| land availability | disponibilidad de suelo | Diferente de control del terreno. |
| planning compatibility | compatibilidad urbanística | Confirmable por planeamiento o criterio administrativo. |
| fibre diversity | diversidad física de fibra | Evitar “fibra diversa” sin explicar rutas separadas. |
| non-binding interest | interés no vinculante | Debe quedar claro que no es reserva, contrato ni inversión. |
| capacity requirement | necesidad de capacidad | Preferible a “requerimiento” en formularios públicos. |
| partner interest | interés de colaboración | Puede incluir suelo, energía, fibra, ingeniería o capital. |
| technical report | informe técnico | Usar “dossier” solo si se habla del PDF completo. |
| verified | comprobado | En badges puede mantenerse “Verificado” si el espacio es limitado. |
| hypothesis | hipótesis | Usar con moderación en páginas comerciales. |
| evidence required | pendiente de comprobar | Más natural que “evidencia requerida” en España. |
| decision pending | decisión pendiente | Usar para fases todavía abiertas. |

Evitar construcciones literales del inglés, exceso de disclaimers y repeticiones de “infraestructura de IA”, “validación”, “evidencia” o “candidato”.
