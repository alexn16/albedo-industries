# Risks and pre-mortem

| Risk | Earliest test | Mitigation / stop rule |
|---|---|---|
| Display costs too much | supplier RFQ | stop ultra-low-cost claim if landed path >$25 |
| Tablets are better | side-by-side workflow trial | pursue only placements where simplicity/TCO wins |
| BLE onboarding is poor | unassisted setup | revise if median setup >3 minutes |
| AI adds little value | compare fixed templates | remove AI claim if users prefer static controls |
| Low margins | landed-cost model | prefer SaaS/OEM or stop consumer plan |
| Fragmented demand | 15 interviews in 3 clusters | focus only with repeated common job |
| Manufacturing capital | DFM and compliance estimate | partner or stop before tooling |
