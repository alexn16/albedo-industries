# First validation cycle

| Test | Spend cap | Pass gate | Kill / revise gate |
|---|---:|---|---|
| Two display/controller combinations | €250 | reliable updates, measured latency <3 s for structured pages | unstable or unusably slow |
| 15 problem interviews | €0 | ≥5 report weekly high-friction persistent-information job | polite concept interest only |
| 5 concierge trials | €250 | ≥3 use it ≥4 days/week for 3 weeks | novelty decays in week one |
| Three supplier conversations | €0 | documented path below $20 at 10k, with lifecycle/MOQ | credible landed BOM remains >$25 |
| Two paid-pilot proposals | €100 | one written paid intent conditional on prototype | no budget owner / no measurable value |

Never ask “do you like it?” Observe the current workaround, frequency, consequence, budget and commitment.
